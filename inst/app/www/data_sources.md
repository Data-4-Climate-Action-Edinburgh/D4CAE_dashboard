# Data preparation and documentation

To keep the dashboard Rshiny app itself streamlined, the data preparation steps 
and intermediate data files are in a separate code repository also on GitHub: 
https://github.com/data4climateactionedinburgh/Data4ClimateActionEdinburgh_Code_etc . 

# Acknowledgments
## Rainfall

The rainfall data is made available under an Open Government Licence by the 
Scottish Environment Protection Agency, SEPA. The files were downloaded from: 
https://www2.sepa.org.uk/rainfall/

## Active Travel 

Both walking and cycling data were from the Cycling Open Data (COD) portal on usmart. 
This portal is run by Cycling Scotland, and hosts over a hundred datasets. 
The Edinburgh cycling and walking data used were all provided to COD by the 
City of Edinburgh Council. The files were downloaded from: 
https://usmart.io/org/cyclingscotland/
